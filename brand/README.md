# SPRAY.LAND brand kit

![SPRAY.LAND brand kit preview](preview-sheet.png)

Logo: **Voxel Spray Can** with the SPRAY.LAND wordmark (Audiowide, outlined). Vector SVGs are in `svg/` and `social/`, PNG exports in `png/`, favicons in `favicon/`, and a PDF of all logos in `pdf/`.

Usage rules, palette, the full file list and the font licence are in [BRAND.md](BRAND.md). Run `src/export.sh` to rebuild everything.

The Audiowide font in `font/` is licensed under the SIL Open Font License 1.1 (`font/OFL.txt`).
