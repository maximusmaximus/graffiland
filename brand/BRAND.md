# spray.land — Brand Kit

**Logo:** Voxel Spray Can — an isometric spray can built from voxel cubes (body graded #ff2d95 at the bottom → violet → #00e5ff at the top, discrete indigo/navy stepped shoulders, orange nozzle cube) releasing a burst of softly glowing cyan cubes, paired with the SPRAY.LAND wordmark.

## Typeface
- **Font:** Audiowide (Regular) by Astigmatic (Brian J. Bonislawsky)
- **License:** SIL Open Font License 1.1 — see `font/OFL.txt` and https://openfontlicense.org
- **Specimen / download:** https://fonts.google.com/specimen/Audiowide
- **Source file:** `font/Audiowide-Regular.ttf` (from github.com/google/fonts, `ofl/audiowide`)
- The wordmark in every SVG is converted to outlined paths, so no font install is needed to display the logo.
- Wordmark set in uppercase `SPRAY.LAND`, Audiowide Regular, tracking −0.018 em, font kerning applied, plus optical kerns `Y.` −0.045 em and `.L` −0.025 em.

## Palette
| Role | Hex |
|---|---|
| Night navy (background, text on light) | `#060a14` |
| Spray cyan (body gradient end, spray burst) | `#00e5ff` |
| Hot magenta (body gradient start) | `#ff2d95` |
| Nozzle orange (accent) | `#ff8c00` |
| White (wordmark on dark) | `#ffffff` |

Supporting shades inside the mark: violet midpoint `#7a45ff`, shoulder indigo `#4430b4`, shoulder navy `#2a2380`.

## Lockup geometry
- Mark height (body + shoulders + nozzle, excluding spray) = 1.08 × wordmark cap height.
- Gap from the mark's right edge (spray included) to the `S` = 0.40 × cap height.
- The optical centre of the can body sits on the midpoint between cap line and baseline.
- **Stacked lockup:** mark height = 2.4 × cap height, centred on the can's vertical axis above the wordmark, 0.45 × cap height gap between the lowest point of the mark and the cap line.

## Usage
- Use the dark-background lockup by default; it is the primary presentation.
- On white or light backgrounds use the `-light` files (navy `#060a14` wordmark).
- Use the **stacked lockup** where the space is closer to square (posters, splash screens, merch); use the horizontal lockup everywhere else.
- Use the **one-colour** files (`-black`, `-white`) only where full colour can't be reproduced: single-ink print, embossing, stamps, laser engraving, watermarks, or over photos. One-colour marks show each cube through thin knockout gaps, so they work on any background with no white fill. Do not tint them in other colours.
- **Clear space:** keep at least 0.5 × mark height (body + shoulders + nozzle) empty on all sides. Every lockup file already includes it.
- **Minimum sizes:** horizontal lockup ≥ 120 px wide; full mark alone ≥ 32 px high.
- **Small sizes:** at 48 px and below use the simplified mark (`sprayland-mark-small-*`, `favicon/*`): 4-row body, 2-stop gradient, enlarged nozzle, 3 solid spray cubes, no seams or glow. At 16 and 32 px use only the simplified mark.
- **Social:** use `social/sprayland-social-avatar.*` for profile pictures (the mark stays inside the circle crop) and `social/sprayland-og-image.*` for link previews (`og:image`, 1200 × 630).
- Do not recolour, stretch, rotate, re-letter the wordmark in another font, rearrange the lockup, or add effects beyond those in the files.

## Files
All logo files are vector SVGs generated by `src/build.py`: the wordmark is outlined paths (no `<text>`, no font reference), there are no embedded raster images or external links, and every file has a `viewBox`. Files are cleaned with svgo (`src/svgo.config.cjs`) with no visible change. The full-colour mark's cyan spray glow is an SVG blur filter. The PDF shows that glow as a small embedded image; all other PDF artwork is vector.

## Rebuilding
`src/export.sh` regenerates everything. It needs python3 with fonttools, uharfbuzz, shapely and Pillow, plus `rsvg-convert` (librsvg) and Node (`npx svgo@3`).
